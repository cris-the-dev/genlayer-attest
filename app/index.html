How a claim is checked

Ownership
the source must contain your tag genlayer-attest:<address>
github_repo
repo exists (GitHub API) and holds .genlayer-attest with your tag; validators judge the README
domain
/.well-known/genlayer-attest.txt holds your tag; no LLM
web
an https page with your tag; validators judge the page
Validators agree if
same verdict and same reason code
Recheck
anyone; unchanged source keeps it active, tag gone or claim unsupported revokes it
Outage
an unreachable source reverts, it never revokes
Request an attestation

Connect a wallet to see your ownership tag.

  1. 01Tag

    Put genlayer-attest:<your address> in the source: a .genlayer-attest file in your repo, a well-known file on your domain, or your page.

  2. 02Check

    The contract fetches the source. If your tag is there, validators judge whether the source supports your statement and must agree on the verdict.

  3. 03Use

    Other contracts call is_attested(address, kind). Anyone can recheck; if the source changes or the tag disappears, it is revoked.
